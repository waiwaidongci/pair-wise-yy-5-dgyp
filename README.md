# 手工织锦四方连续接版与冻结复核台

由手工织锦纹样排版台扩展而来。直接打开 `index.html` 使用。

## 功能

- 网格绘制、色线统计、断线风险提示、撤销重做、本地保存、导出 JSON，重开后一致。
- 重复单元（默认 6×6，可改起点与宽高）按 6×6 复制平铺，预览四方连续效果。
- 接版判定：平铺越界、接缝对色断点、错位超过一格，任一发生即整次拒绝并保留原画布。
- 同版仅留一条待复核接版，新接版提交即替换旧件；复核人须与制版人不同，通过后冻结为发布版。
- 基础块、色线、行列数或重复单元变化会改变指纹，旧接版随即失效，需重算后再复核。

## 模块

- `js/entry.js` 入口模块：界面、画布交互、撤销重做、统计与导出。
- `js/judge.js` 判定模块：指纹、越界、接缝对色与错位的纯函数判定。
- `js/archive.js` 版本存档模块：待复核接版、复核冻结、发布版持久化。
