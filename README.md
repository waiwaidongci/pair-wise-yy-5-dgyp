# 手工织锦纹样排版台 · 四方连续接版与冻结复核

直接打开 `index.html` 使用。

- **绘制**：网格填色、基础纹样块、用色统计、断线风险提示、撤销重做、本地保存、导出 JSON（重开后一致）。
- **接版**：6×6 重复单元（黑框标出）按错位量四方连续平铺预览；接缝对色断点、错位超过一格或平铺越界时整次拒绝并保留原画布。
- **复核**：同版仅留一条待复核接版，复核人须与制版人不同，通过后冻结为发布版进入版本存档；基础块、色线、行列数或重复单元变化会让旧接版失效需重算。

## 模块拆分

| 文件 | 职责 |
| --- | --- |
| `js/entry.js` | 入口：画布交互、渲染、撤销重做、本地保存与导出 |
| `js/judge.js` | 判定：接版校验（断点/错位/越界）、平铺映射、版本指纹 |
| `js/archive.js` | 版本存档：待复核接版唯一性、复核冻结、发布版存档 |
